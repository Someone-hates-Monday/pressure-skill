# 学科与「写明白」歧义 — 快速备忘（Agent 用）

## 为什么容易猜错

在 **计算机科研**里，「PPT/材料写明白」可能指完全不同载体：

| 可能含义 | 典型证据 | 误判风险 |
|----------|----------|----------|
| **数学式推导与指标** | 主定理、假设、引理链、复杂度/界、训练目标推导 | 若只补代码与流程图，仍会被认为「没写清楚」 |
| **系统与实现** | 架构图、模块接口、复现配置、消融 | 偏理论导师可能认为「工程细节不是重点」 |
| **实验科学叙事** | 假设-实验-结果-失败路径 | 与「先数学界定问题」混用时会打架 |

**规则**：在画像阶段必须问清 **对方更吃哪一类载体**（可多选），再写意图推测；缺省时意图推测**必须**列出 2～3 种互斥解读并标置信度分散。

## 建议问法（嵌入向导 §3H）

- 课题子领域（例：理论/机器学习/系统/安全/交叉）  
- 对方更常表扬的材料长什么样（公式多 / 代码多 / 图多 / 长文）  
- 「写明白」若只能三选一：**推导为主 / 实验与图表为主 / 代码与系统为主**
